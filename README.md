# STM32 - Virtus-CC

Atividades da Formacao em Sistemas Embarcados Virtus-CC (NUCLEO-F767ZI).

| Atividade | Descricao |
|---|---|
| [Lab GPIO e NVIC - atividade 01](lab%20gpio-nvic%20stm32%20-%20atividade01/atividade_01-lab-gpio-nvic/README.md) | GPIO-Link: protocolo de comunicacao entre duas STM32 usando apenas GPIO + EXTI. Criterio otimizado: **robustez**. |
| [Lab Timer e UART - atividade 02](lab%20timer-uart%20stm32%20-%20atividade02/atividade_02-lab-timer-uart/README.md) | Gerador senoidal: PWM de 100 kHz com duty senoidal (DDS) + filtro RC, frequencia ajustavel via UART (1 Hz a 1 kHz). |
| [Lab I2C - atividade 03](lab%20i2c%20stm32%20-%20atividade03/atividade_03-lab-i2c/README.md) | Estimacao de atitude: MPU6050 + OLED SSD1306 no I2C, roll/pitch/yaw por filtro complementar, tela de dados e animacao (horizonte artificial + bussola). |
| [Lab ADC, DAC e DMA - atividade 04](lab%20adc-dac-dma%20stm32%20-%20atividade04/atividade_04-lab-adc-dac-dma/README.md) | Digipot com LED + LDR: DAC aciona o LED, ADC+DMA mede o divisor, LUT de 256 entradas recalibravel pela UART via DMA, aplicacao exemplo de resistencia em ohms (malha fechada). |
